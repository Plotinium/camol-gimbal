# Camol Gimbal

An addon for [Camol](https://www.curseforge.com/minecraft/mc-mods/camol) (Minecraft 1.21.1,
NeoForge). The Gimbal is a tool that turns and reshapes camouflaged blocks: a camouflaged trapdoor
can stand upright, a log can lie on any axis.

Camol is required and is not included. License: MIT (see `LICENSE`).

How to use it: [player guide](docs/PLAYER_GUIDE.md). Problems and ideas go in the
[issues](https://github.com/Plotinium/camol-gimbal/issues).

Camol Gimbal is an unofficial addon, not made by Camol's author. The radial menu is adapted from
Create's wrench menu (see `THIRD_PARTY_NOTICES.md`).

## AI disclosure

This mod was made with generative AI. The code, the translations and the written text, including the
project page and the documentation, were produced by an AI coding assistant. The item texture and the
icon are AI drawings that Plotinium retouched by hand. Plotinium had the idea, made the choices about
how the mod behaves and looks, and tests it in game. The mod itself uses no AI while you play.

## Build

```
./gradlew build
```

Java 21. The jar is written to `build/libs/`.
